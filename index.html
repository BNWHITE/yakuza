Vecteurs gaussiens, covariance, corrélation, indépendance et applications avancées

TD5-1 - Variable normale standardisée

Moyen

Énoncé : Soit X ~ N(2, 2²). On pose T = (X - μ)/σ

T = (X - μ)/σ = (X - 2)/2

Solution :

a) T = (X - 2)/2 suit une loi normale centrée réduite N(0,1)
b) Événement {X < 1.5} équivaut à {T < (1.5-2)/2 = -0.25}
P(X < 1.5) = P(T < -0.25) = Φ(-0.25) = 1 - Φ(0.25) ≈ 1 - 0.5987 = 0.4013
c) Événement {X > 2} équivaut à {T > 0}
P(X > 2) = P(T > 0) = 0.5
d) Événement {-1 ≤ T < 1} équivaut à {2 + 2×(-1) ≤ X < 2 + 2×1} = {0 ≤ X < 4}
P(-1 ≤ T < 1) = Φ(1) - Φ(-1) = 0.8413 - 0.1587 = 0.6826
e) Valeurs de x :
• P(X < x) = 0.76 ⇒ Φ((x-2)/2) = 0.76 ⇒ (x-2)/2 = 0.71 ⇒ x = 3.42
• P(X > x) = 0.6 ⇒ P(X < x) = 0.4 ⇒ (x-2)/2 = -0.25 ⇒ x = 1.5
• P(0 ≤ X < x) = 0.40 ⇒ Φ((x-2)/2) - Φ(-1) = 0.40 ⇒ Φ((x-2)/2) = 0.40 + 0.1587 = 0.5587
⇒ (x-2)/2 = 0.15 ⇒ x = 2.3

TD5-2 - Variables corrélées et indépendance

Difficile

Énoncé : X ~ N(0,1), ε telle que P(ε=+1)=P(ε=-1)=1/2, Y = εX

Solution :

a) Fonction de répartition de Y :
F_Y(y) = P(Y ≤ y) = P(εX ≤ y)
= P(ε=1, X≤y) + P(ε=-1, -X≤y)
= ½P(X≤y) + ½P(X≥-y)
= ½Φ(y) + ½[1 - Φ(-y)] = ½Φ(y) + ½Φ(y) = Φ(y)
Donc Y ~ N(0,1)
b) Cov(X,Y) = E(XY) - E(X)E(Y) = E(εX²) - 0 = E(ε)E(X²) = 0×1 = 0
Donc X et Y sont non corrélées
c) P(X+Y=0) = P(X+εX=0) = P(X(1+ε)=0)
Si ε=1 ⇒ P(2X=0) = P(X=0) = 0 (car X continue)
Si ε=-1 ⇒ P(0=0) = 1
Donc P(X+Y=0) = ½×0 + ½×1 = 0.5

Le vecteur (X,Y) n'est pas gaussien car X+Y n'est pas gaussienne :
P(X+Y=0) = 0.5 ≠ 0 pour une variable gaussienne continue

X et Y ne sont pas indépendantes car la connaissance de X donne des informations sur |Y|

TD5-3 - Vecteur gaussien et transformations

Difficile

Énoncé : (X,Y) vecteur gaussien centré avec E(X²)=4, E(Y²)=1, et (2X+Y) et (X-3Y) indépendantes

Solution :

a) On a Var(X)=4, Var(Y)=1
Cov(2X+Y, X-3Y) = 2Var(X) -6Cov(X,Y) + Cov(X,Y) -3Var(Y)
= 2×4 -5Cov(X,Y) -3×1 = 8 -5Cov(X,Y) -3 = 5 -5Cov(X,Y)

Comme (2X+Y) et (X-3Y) sont indépendantes, leur covariance est nulle :
5 -5Cov(X,Y) = 0 ⇒ Cov(X,Y) = 1

Coefficient de corrélation : r = Cov(X,Y)/(σ_Xσ_Y) = 1/(2×1) = 0.5

La loi de (X,Y) est N(0, V) avec V = [[4, 1], [1, 1]]
b) (X+Y, 2X-Y) est une transformation linéaire de (X,Y) donc c'est un vecteur gaussien

Soit Z = [X+Y, 2X-Y]ᵀ = A[X,Y]ᵀ avec A = [[1,1],[2,-1]]

Matrice de covariance : V_Z = A V Aᵀ
A V = [[1,1],[2,-1]] × [[4,1],[1,1]] = [[5,2],[7,1]]
V_Z = [[5,2],[7,1]] × [[1,2],[1,-1]] = [[7,8],[8,13]]

Donc (X+Y, 2X-Y) ~ N(0, [[7,8],[8,13]])

TD5-4 - Espérances conditionnelles et covariance

Moyen

Énoncé : Reprise du TD4-2 avec calcul d'espérances conditionnelles

Solution :

a) E(X|Y=1) à partir de la loi conditionnelle :
P(X=-2|Y=1) = 0.2/0.3 = 2/3
P(X=0|Y=1) = 0.1/0.3 = 1/3
P(X=1|Y=1) = 0/0.3 = 0

E(X|Y=1) = (-2)×(2/3) + 0×(1/3) + 1×0 = -4/3 ≈ -1.333
b) E(X|Y≠2) :
P(Y≠2) = 1 - P(Y=2) = 1 - 0.2 = 0.8
P(X=-2|Y≠2) = 0.4/0.8 = 0.5
P(X=0|Y≠2) = 0.2/0.8 = 0.25
P(X=1|Y≠2) = 0.2/0.8 = 0.25

E(X|Y≠2) = (-2)×0.5 + 0×0.25 + 1×0.25 = -1 + 0.25 = -0.75
c) E(XY) et Cov(X,Y) :
E(XY) = ΣΣ xy P(X=x,Y=y)
= (-2)×(-1)×0.2 + (-2)×1×0.2 + (-2)×2×0.05
+ 0×(-1)×0.1 + 0×1×0.1 + 0×2×0.05
+ 1×(-1)×0.2 + 1×1×0 + 1×2×0.1
= 0.4 -0.4 -0.2 + 0 + 0 + 0 -0.2 + 0 + 0.2 = -0.2

E(X) = (-2)×0.45 + 0×0.25 + 1×0.3 = -0.9 + 0.3 = -0.6
E(Y) = (-1)×0.5 + 1×0.3 + 2×0.2 = -0.5 + 0.3 + 0.4 = 0.2

Cov(X,Y) = E(XY) - E(X)E(Y) = -0.2 - (-0.6)×0.2 = -0.2 + 0.12 = -0.08
d) Z = X+Y :
• Z = -3 : P=0.2 (X=-2,Y=-1)
• Z = -1 : P=0.2+0.1=0.3 (X=-2,Y=1 et X=0,Y=-1)
• Z = 0 : P=0.2+0.1=0.3 (X=-2,Y=2 et X=1,Y=-1)
• Z = 1 : P=0.1+0=0.1 (X=0,Y=1 et X=1,Y=0)
• Z = 2 : P=0.05+0.1=0.15 (X=0,Y=2 et X=1,Y=1)
• Z = 3 : P=0.05 (X=1,Y=2)

E(Z) = E(X)+E(Y) = -0.6+0.2 = -0.4
V(Z) = V(X)+V(Y)+2Cov(X,Y)
E(X²)=4×0.45+0×0.25+1×0.3=1.8+0.3=2.1, V(X)=2.1-0.36=1.74
E(Y²)=1×0.5+1×0.3+4×0.2=0.5+0.3+0.8=1.6, V(Y)=1.6-0.04=1.56
V(Z)=1.74+1.56+2×(-0.08)=3.3-0.16=3.14

TD1 - Probabilités Conditionnelles

📋 Rappels théoriques

Théorème de Bayes : P(A|B) = P(B|A) · P(A) / P(B)

Probabilités totales : P(B) = Σ P(A_i) · P(B|A_i)

Indépendance : P(A∩B) = P(A) · P(B)

Si A et B indépendants ⟹ A et B̅ indépendants

💡 Combinaisons

Permutations : n! arrangements de n objets

Arrangements : A(n,k) = n!/(n-k)!

Combinaisons : C(n,k) = n!/(k!(n-k)!)

📝 Exercices

Exercice 1 - Indépendance d'événements

Moyen

Énoncé : Montrer que si A et B sont indépendants, alors A et B̅ sont aussi indépendants.

Solution :

On sait que A = (A∩B) ∪ (A∩B̅) avec les deux événements disjoints
Donc P(A) = P(A∩B) + P(A∩B̅)

Si A et B indépendants : P(A∩B) = P(A)·P(B)
Alors P(A∩B̅) = P(A) - P(A)·P(B) = P(A)·(1-P(B)) = P(A)·P(B̅)

✓ Donc A et B̅ sont indépendants

Exercice 2 - Probabilités totales

Moyen

Énoncé : Dans une bibliothèque : 30% des livres sur étagère haute, 50% sur moyenne, 20% sur basse. Sur l'étagère haute : 25% romans. Sur moyenne : 40% romans. Sur basse : 80% romans. Quelle est la probabilité de choisir un roman au hasard ?

Solution :

Événements : H (haute), M (moyenne), B (basse), R (roman)

P(R) = P(H)·P(R|H) + P(M)·P(R|M) + P(B)·P(R|B)
P(R) = 0.30×0.25 + 0.50×0.40 + 0.20×0.80
P(R) = 0.075 + 0.20 + 0.16 = 0.435

✓ La probabilité est 43.5%

Exercice 3 - Combinaisons

Facile

Énoncé : Combien de mains de 5 cartes différentes peut-on faire avec un jeu de 32 cartes ?

Solution :

Il s'agit d'une combinaison (l'ordre n'importe pas)
C(32,5) = 32!/(5!×27!) = (32×31×30×29×28)/(5×4×3×2×1)
C(32,5) = 20,358,520/120 = 201,376

✓ Il y a 201,376 mains possibles

Exercice 4 - Dés et probabilités conditionnelles

Moyen

Énoncé : On jette deux dés. Soit S la somme des deux dés. Calculer P(S≥10 | premier dé = 5).

Solution :

Si le premier dé = 5, alors S≥10 ⟺ deuxième dé ≥ 5
Valeurs possibles pour le 2ème dé : {5, 6}
P(S≥10 | D1=5) = P(D2≥5) = 2/6 = 1/3

✓ La probabilité est 1/3 ≈ 33.3%

Exercice 5 - Bayes appliqué

Difficile

Énoncé : Un test médical détecte une maladie avec 99% de précision (sensibilité). La maladie touche 0.1% de la population. Si le test est positif, quelle est la probabilité d'être réellement malade ?

Solution :

Soit M : malade, T+ : test positif
P(M) = 0.001, P(M̅) = 0.999
P(T+|M) = 0.99 (sensibilité)
P(T+|M̅) = 0.01 (faux positif)

P(T+) = P(M)·P(T+|M) + P(M̅)·P(T+|M̅)
P(T+) = 0.001×0.99 + 0.999×0.01 = 0.00099 + 0.00999 = 0.01098

P(M|T+) = P(T+|M)·P(M) / P(T+)
P(M|T+) = (0.99×0.001) / 0.01098 ≈ 0.090 = 9%

✓ Seulement 9% de chances d'être malade !
Paradoxe : test très précis mais maladie très rare

TD2 - Lois Discrètes Usuelles

📋 Lois de probabilités discrètes

1. Loi Binomiale B(n,p)

P(X=k) = C(n,k) · p^k · (1-p)^(n-k)
E(X) = n·p
Var(X) = n·p·(1-p)

Usage : n épreuves indépendantes, succès avec probabilité p

2. Loi de Poisson P(λ)

P(X=k) = (λ^k · e^(-λ)) / k!
E(X) = λ
Var(X) = λ

Usage : événements rares, approximation binomiale si n grand et p petit

3. Loi Géométrique G(p)

P(X=k) = (1-p)^(k-1) · p
E(X) = 1/p
Var(X) = (1-p)/p²

Usage : nombre d'essais jusqu'au premier succès

📝 Exercices

Exercice 6 - Loi Binomiale

Facile

Énoncé : On lance 10 fois une pièce équilibrée. Quelle est la probabilité d'obtenir exactement 6 fois pile ?

Solution :

X ~ B(10, 0.5)
P(X=6) = C(10,6) · (0.5)^6 · (0.5)^4
C(10,6) = 10!/(6!×4!) = 210
P(X=6) = 210 · (0.5)^10 = 210/1024 ≈ 0.205

✓ Probabilité ≈ 20.5%

Exercice 7 - Loi de Poisson

Moyen

Énoncé : Un magasin reçoit en moyenne 4 clients par heure. Quelle est la probabilité de recevoir exactement 5 clients dans la prochaine heure ? Au moins 6 clients ?

Solution :

X ~ P(4)

P(X=5) = (4^5 · e^(-4)) / 5!
P(X=5) = (1024 · e^(-4)) / 120
P(X=5) ≈ (1024 × 0.0183) / 120 ≈ 0.156
✓ Exactement 5 clients : 15.6%

P(X≥6) = 1 - P(X≤5)
= 1 - [P(X=0) + P(X=1) + P(X=2) + P(X=3) + P(X=4) + P(X=5)]
= 1 - 0.785 ≈ 0.215
✓ Au moins 6 clients : 21.5%

Exercice 8 - Loi Géométrique

Moyen

Énoncé : On lance un dé jusqu'à obtenir un 6. Quelle est la probabilité d'y arriver en moins de 5 lancers ? Quel est le nombre moyen de lancers ?

Solution :

X ~ G(1/6)

P(X<5) = P(X=1) + P(X=2) + P(X=3) + P(X=4)
P(X=k) = (5/6)^(k-1) · (1/6)

P(X=1) = 1/6
P(X=2) = (5/6)·(1/6) = 5/36
P(X=3) = (5/6)²·(1/6) = 25/216
P(X=4) = (5/6)³·(1/6) = 125/1296

P(X<5) = 1/6 + 5/36 + 25/216 + 125/1296 ≈ 0.518
✓ Probabilité : 51.8%

E(X) = 1/p = 6 lancers en moyenne
✓ Nombre moyen : 6 lancers

Exercice 9 - Approximation Poisson

Difficile

Énoncé : Un composant électronique a 0.1% de chances d'être défectueux. Sur un lot de 1000, calculer la probabilité d'avoir exactement 2 défectueux (avec binomiale puis Poisson).

Solution :

Méthode 1 : Binomiale
X ~ B(1000, 0.001)
P(X=2) = C(1000,2) · (0.001)² · (0.999)^998
C(1000,2) = 499,500
P(X=2) ≈ 499,500 × 10^(-6) × 0.368 ≈ 0.184

Méthode 2 : Approximation Poisson
λ = n·p = 1000 × 0.001 = 1
X ~ P(1)
P(X=2) = (1² · e^(-1)) / 2! = e^(-1)/2 ≈ 0.368/2 ≈ 0.184

✓ Les deux méthodes donnent ~18.4%
✓ Approximation Poisson excellente car n grand et p petit

TD3 - Variables Continues

📋 Lois continues usuelles

1. Loi Uniforme U(a,b)

f(x) = 1/(b-a) si x∈[a,b], 0 sinon
E(X) = (a+b)/2
Var(X) = (b-a)²/12
F(x) = (x-a)/(b-a) pour x∈[a,b]

2. Loi Exponentielle E(λ)

f(x) = λe^(-λx) si x≥0
E(X) = 1/λ
Var(X) = 1/λ²
F(x) = 1 - e^(-λx)
Propriété : sans mémoire P(X>s+t|X>s) = P(X>t)

3. Loi Normale N(μ,σ²)

f(x) = (1/(σ√(2π)))·exp(-(x-μ)²/(2σ²))
E(X) = μ
Var(X) = σ²
Règle 68-95-99.7 : ±1σ ≈ 68%, ±2σ ≈ 95%, ±3σ ≈ 99.7%
Standardisation : Z = (X-μ)/σ ~ N(0,1)

📝 Exercices

Exercice 10 - Loi Uniforme

Facile

Énoncé : Un bus arrive aléatoirement entre 8h00 et 8h20. Vous arrivez à 8h05. Quelle est la probabilité d'attendre moins de 5 minutes ?

Solution :

X ~ U(0,20) où X est le temps d'arrivée en minutes après 8h00
Vous arrivez à t=5, vous attendez <5min si bus arrive entre 5 et 10
P(5≤X≤10) = (10-5)/(20-0) = 5/20 = 1/4

✓ Probabilité = 25%

Exercice 11 - Loi Exponentielle

Moyen

Énoncé : La durée de vie d'un disque dur suit E(λ) avec durée moyenne 5 ans. Quelle probabilité de panne avant 1 an ? Quelle garantie donner pour que P(panne) < 0.01 ?

Solution :

E(X) = 1/λ = 5 donc λ = 0.2
F(x) = 1 - e^(-λx)

P(X<1) = F(1) = 1 - e^(-0.2) ≈ 1 - 0.8187 = 0.1813
✓ Probabilité panne < 1an : 18.13%

Pour garantie t : 1 - e^(-0.2t) < 0.01
e^(-0.2t) > 0.99 ⟹ -0.2t > ln(0.99)
t < -ln(0.99)/0.2 ≈ 0.05 ans ≈ 18 jours
✓ Garantir maximum 18 jours

P(X<5) = P(Z<(5-13)/3) = P(Z<-2.67) ≈ 0.004

P(12 ✓ 25.86% entre 12 et 14

Top 10% : P(X>x) = 0.10 ⟹ P(Z>(x-13)/3) = 0.10
(x-13)/3 = 1.28 ⟹ x ≈ 16.84
✓ Note ≥ 16.84 pour top 10%

Exercice 13 - Théorème de Tchebychev

Difficile

Énoncé : Pour X~N(13,3²), comparer P(|X-13|>6) calculée exactement et avec l'inégalité de Tchebychev.

Solution :

Calcul exact :
P(|X-13|>6) = P(X<7 ou X>19)
= P(Z<-2) + P(Z>2) = 2×0.0228 = 0.0456
✓ Exacte : 4.56%

Ici k = 6/3 = 2
P(|X-13|≥6) ≤ 1/4 = 0.25
✓ Borne de Tchebychev : ≤25%

L'inégalité est large mais toujours valide !
Avantage : valable pour TOUTE distribution

Bruit Thermique

📋 Formule fondamentale

P_bruit = k·T·B

k = 1.38×10⁻²³ J/K (constante de Boltzmann)
T = température en Kelvin (typiquement 290K = 17°C)
B = bande passante en Hz

Conversion en dBm :
P_bruit(dBm) = 10·log₁₀(P_bruit(W) × 10³)

📝 Exercices

Exercice 15 - Calcul du bruit

Moyen

Énoncé : Calculer la puissance du bruit thermique pour une bande passante de 10 MHz à température ambiante (T=290K).

Solution :

P_bruit(W) = k·T·B
P_bruit = 1.38×10⁻²³ × 290 × 10×10⁶
P_bruit ≈ 4.002×10⁻¹⁴ W

Conversion en dBm :
P_bruit(dBm) = 10·log₁₀(4.002×10⁻¹⁴ × 10³)
P_bruit(dBm) = 10·log₁₀(4.002×10⁻¹¹)
P_bruit(dBm) ≈ -103.98 dBm

✓ Puissance du bruit : -104 dBm

Exercice 16 - Bilan WiFi indoor

Moyen

Énoncé : Un point d'accès WiFi émet à 20 dBm avec une antenne de gain 3 dBi. Calculer la puissance reçue à 30 m en indoor à 2.4 GHz.

Solution :

Atténuation indoor :
A = 15.5 + 55·log₁₀(30)
A = 15.5 + 55×1.477 = 96.74 dB

Bilan de liaison (avec G_r = 0 dBi) :
P_r = P_e + G_e - A + G_r
P_r = 20 + 3 - 96.74 + 0
P_r = -73.74 dBm

✓ Puissance reçue : -73.74 dBm

Exercice 17 - Comparaison modèles

Difficile

Énoncé : Comparer l'atténuation à 100m pour les modèles espace libre (2.4 GHz) et indoor (2.4 GHz). Expliquer la différence.

Solution :

Espace libre :
A_EL = 32.4 + 20·log₁₀(0.1) + 20·log₁₀(2400)
A_EL = 32.4 - 20 + 67.6 = 80 dB

Indoor :
A_indoor = 15.5 + 55·log₁₀(100)
A_indoor = 15.5 + 55×2 = 125.5 dB

Différence : 125.5 - 80 = 45.5 dB

✓ L'atténuation indoor est 45.5 dB supérieure !
✓ Raison : murs, obstacles, réflexions multiples
✓ Le modèle indoor est beaucoup plus pessimiste (réaliste)

Exercice 18 - Portée WiFi

Moyen

Énoncé : Un émetteur WiFi (2.4 GHz) a une puissance de 23 dBm, gain antenne 5 dBi. Seuil de sensibilité du récepteur : -85 dBm. Calculer la portée max en indoor.

Solution :

Budget de liaison :
-85 = 23 + 5 - A + 0
A = 113 dB

Modèle indoor : A = 15.5 + 55·log₁₀(d)
113 = 15.5 + 55·log₁₀(d)
55·log₁₀(d) = 97.5
log₁₀(d) = 1.773
d = 10^1.773 ≈ 59.3 m

✓ Portée maximale : environ 59 mètres

Exercice 19 - Impact de la fréquence

Difficile

Énoncé : Comparer la portée en espace libre à 2.4 GHz et 5 GHz avec même puissance 20 dBm, gains 0 dBi, sensibilité -90 dBm.

Solution :

Budget : -90 = 20 + 0 - A + 0 ⟹ A = 110 dB

À 2.4 GHz (2400 MHz) :
110 = 32.4 + 20·log₁₀(d_km) + 20·log₁₀(2400)
110 = 32.4 + 20·log₁₀(d_km) + 67.6
20·log₁₀(d_km) = 10
d_km = 10^0.5 ≈ 3.16 km
✓ Portée à 2.4 GHz : 3.16 km

À 5 GHz (5000 MHz) :
110 = 32.4 + 20·log₁₀(d_km) + 20·log₁₀(5000)
110 = 32.4 + 20·log₁₀(d_km) + 74
20·log₁₀(d_km) = 3.6
d_km = 10^0.18 ≈ 1.51 km
✓ Portée à 5 GHz : 1.51 km

Conclusion : 2.4 GHz a 2× plus de portée !
Les fréquences basses portent plus loin

Capacité de Shannon

📋 Théorème de Shannon-Hartley

C = B·log₂(1 + SINR)

C : capacité du canal (bit/s)
B : bande passante (Hz)
SINR : rapport signal sur interférence + bruit (linéaire)

Efficacité spectrale : η = C/B (bit/s/Hz)
η = log₂(1 + SINR)

Conversion dB : SINR(linéaire) = 10^(SINR(dB)/10)

Exercice 20 - Capacité théorique

Difficile

Énoncé : Canal WiFi : bande 20 MHz, SINR = 20 dB. Calculer la capacité théorique. Combien de temps pour transférer un fichier de 100 Mo ?

Solution :

SINR(dB) = 20 dB ⟹ SINR = 10^(20/10) = 100

Capacité de Shannon :
C = B·log₂(1 + SINR)
C = 20×10⁶ × log₂(101)
C = 20×10⁶ × 6.658 ≈ 133.16 Mbps

Fichier 100 Mo = 800 Mbits
Temps = 800 / 133.16 ≈ 6.0 secondes

✓ Capacité : 133 Mbps
✓ Temps : 6 secondes
(En pratique, overhead protocolaire réduit le débit)

Exercice 21 - Efficacité spectrale

Difficile

Énoncé : Un réseau 4G utilise 10 MHz de bande et atteint 30 Mbps. Calculer l'efficacité spectrale η. Quel SINR minimum est requis ?

Solution :

Efficacité spectrale :
η = C/B = 30×10⁶ / 10×10⁶ = 3 bit/s/Hz

De C = B·log₂(1 + SINR) :
η = log₂(1 + SINR)
3 = log₂(1 + SINR)
1 + SINR = 2³ = 8
SINR = 7 (linéaire)
SINR(dB) = 10·log₁₀(7) ≈ 8.45 dB

✓ Efficacité : 3 bit/s/Hz
✓ SINR minimum : 8.45 dB

Exercice 22 - Cas pratique Campus IoT

Difficile

Énoncé : Campus 5000 m² sur 3 étages, 80 salles avec 3 capteurs chacun (T°, humidité, présence). Données : 100 bytes toutes les 5 min. Dimensionner l'architecture complète (BLE → passerelles → WiFi → serveur).

Solution :

Niveau 1 : Capteurs → Passerelles BLE
Total capteurs = 80 × 3 = 240 capteurs
Chaque passerelle : 20 capteurs max
Passerelles BLE = ⌈240/20⌉ = 12 passerelles
Répartition : 4 passerelles par étage

Débit par capteur :
100 bytes / 5 min = 20 bytes/min = 0.33 bytes/s
= 2.67 bps par capteur
Par passerelle : 20 × 2.67 = 53.4 bps

Niveau 2 : Passerelles → AP WiFi
Débit total : 12 × 53.4 bps = 641 bps ≈ 0.6 kbps
Avec overhead × 100 : 60 kbps requis
WiFi (54 Mbps) : largement suffisant !

Architecture recommandée :
✓ 12 passerelles BLE (4 par étage)
✓ 3 AP WiFi (1 par étage) + 1 backup
✓ 1 serveur local ou cloud
✓ Backup 4G pour redondance

Bilan de liaison à vérifier :
BLE : portée 10m OK pour salles
WiFi : portée 40m OK pour étages
Marge ≥ 10 dB recommandée

Unités de Télécommunications

📋 Conversions d'unités

P(dBW) = 10·log₁₀(P(W))
P(dBm) = 10·log₁₀(P(mW)) = P(dBW) + 30
P_r(dBm) = P_e(dBm) - A(dB)

Formule inverse :
P(W) = 10^(P(dBW)/10)
P(mW) = 10^(P(dBm)/10)

💡 Exemples de conversion

P = 1 mW → 0.001 W, 0 dBm, -30 dBW

P = 1 W → 1000 mW, 0 dBW, 30 dBm

P = 21 dBm → 125.89 mW, 0.12589 W

P = -80 dBm → 0.0000001 mW, 10⁻¹⁰ W

Exercice 24 - Calcul de puissance

Moyen

Énoncé : Un émetteur a une puissance de 2 W. Après une atténuation de 15 dB, quelle est la puissance reçue en dBm et en mW ?

Solution :

P_émetteur = 2 W = 10·log₁₀(2000) ≈ 33.01 dBm
P_reçue = 33.01 - 15 = 18.01 dBm
P_reçue(mW) = 10^(18.01/10) ≈ 63.25 mW

✓ Puissance reçue : 18.01 dBm = 63.25 mW

Exercice 25 - Bilan complet

Difficile

Énoncé : Système avec P_émetteur = 30 dBm, G_émetteur = 5 dBi, atténuation = 110 dB, G_récepteur = 2 dBi. Calculer P_reçue en dBm et en μW.

Solution :

P_reçue = P_émetteur + G_émetteur - Atténuation + G_récepteur
P_reçue = 30 + 5 - 110 + 2 = -73 dBm

Conversion en μW :
P(μW) = 10^(P(dBm)/10) × 1000
P(μW) = 10^(-73/10) × 1000 = 10^(-7.3) × 1000
P(μW) = 5.01 × 10⁻⁸ × 1000 = 0.0501 μW

✓ P_reçue = -73 dBm = 0.0501 μW
